# Comfety — Consolidated Implementation Plan (Nov 14 – Nov 20, 2026)

## Reference Artifacts

- `GEMINI.md`: Architectural invariants, free-tier rate limits, and Gemini 3.8 Flash rules.
- `USER_JOURNEYS.md`: Step-by-step interaction flows for Blind, Mute, Deaf, and Deaf-Mute personas.
- `docs/design/DESIGN.md` & `docs/design/screens/`: Stitch visual design tokens and screen references.

## Native & Asset Prerequisites (Completed / Required)

- **Native Build Configuration:** `expo-audio` + `expo-asset` installed (`expo-av` removed); `minSdkVersion: 26` and `buildArchs: ["arm64-v8a"]` configured in `app.json`; custom development client `.apk` compiled via EAS (`SDK 58.0.0`).
- **Offline TFLite Weights & Metro Bundler:** Official Google `uint8` quantized `efficientdet-lite0.tflite` saved at `assets/models/efficientdet-lite0.tflite`, with `'tflite'` added to `resolver.assetExts` in `metro.config.js`.
