# Comfety Design System (React Native Accessibility Mobile UI)

## Color Palette (High-Contrast Dark Mode)

- Background Primary: #090D16 (Deep Obsidian)
- Surface Elevated: #131B2E (Slate Navy Cards)
- Surface Interactive: #1E293B (Elevated Chips & Controls)
- Text Primary: #F8FAFC (Pure Off-White, 16:1 contrast ratio)
- Text Secondary: #CBD5E1 (Muted Silver)
- Accent Primary: #38BDF8 (High-Visibility Sky Blue for primary actions)
- Accent Secondary: #34D399 (Emerald Green for active listening / safe status)
- Warning Hazard: #F59E0B (Amber for caution alerts)
- Danger Hazard: #EF4444 (Crimson Red for immediate obstacle warnings)
- Border Subtle: #334155 (1.5px crisp structural borders)

## Typography & Script Support

- Primary Font: Inter / System Sans-Serif (Latin)
- Bilingual Script Support: Noto Nastaliq Urdu (Right-to-Left alignment support for Urdu utterances)
- Transcript Body Size: 22px (Line height 32px, Semi-Bold)
- Button & Chip Label Size: 17px (Bold)
- Caption & Status Size: 14px (Medium, uppercase tracking)

## Layout & Accessibility Rules

- Minimum Touch Target: 48dp x 48dp on all interactive controls
- Card Corner Radius: 20px
- Chip / Button Corner Radius: 14px
- Screen Padding: 16px horizontal safe-area margins
- Visual Hierarchy: Maximum 3 primary focal zones per screen; zero decorative clutter
